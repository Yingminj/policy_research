## 一句话总结

针对 chunk-based VLA「固定执行步长 → 重规划时刻与任务阶段脱节」这一失败模式，本文提出 **BCP（Bernoulli-Continuation Policy）**：在**冻结的**基座 VLA 上挂一个 16.4M 参数的轻量头，把「执行多少步后重规划」拆成一串 continue-or-replan 的伯努利决策，用 GRPO + Replanning-Efficiency Reward 从轨迹级结果训练；在 RoboTwin 2.0 50 任务上把 LingBot-VLA 从 89.88% 提到 93.94%（13 个低成功率任务 +11.08%），真机两项任务 74%→92%、44%→84%，且整体 runtime **反而更低**（10.43s→10.24s）。

## 研究背景与动机

### 领域现状

action chunking（Zhao et al. 2023）已是当前 VLA 的标配：模型一次预测未来 H 步动作序列，机器人执行其中 E 步后再查询模型。这样做降低了昂贵的模型推理频率，也改善了动作的时序一致性（Chi et al. 2025）。OpenVLA、π₀、LingBot-VLA 等主流工作都采用**固定的执行步长 E**（论文实验中 RoboTwin 系列基座是 H = E = 50）。

### 现有痛点

固定 E 把重规划变成了一个**与任务进度无关的周期性时刻表**。粗放的自由空间运动阶段，长 chunk 是好事；但在抓取、插入、对齐这类精度敏感阶段，微小的位姿/接触误差会迅速累积，机器人必须在进入这些阶段**之前**重新观测。固定时刻表无法保证这一点。

### 核心矛盾（论文用一个实验把它量化了）

Phase-shift 实验（Table 1 + Figure 1）：所有变体都用同样的 50 步固定步长，只是第一个 chunk 只执行 φ 步就重规划，此后每 50 步一次——**唯一差别是重规划边界落在哪里**。在 RoboTwin 2.0 的 50 个任务上：

| | 成功率 |
|---|---|
| 原始（φ=50） | 88.52% |
| 逐任务最优 phase（事后 oracle 上界） | 93.65% |
| 逐任务最差 phase（下界） | 82.50% |
| **Gap** | **11.30%** |

Figure 1 的 *Place Dual Shoes* 例子很直观：φ=32 时机器人带着过时的夹爪闭合量去抓，失败；φ=23 时重规划边界恰好落在操作阶段之前，成功。

更关键的是附录 Figure A.2：50 个任务的**最优 phase 在 1–50 上大致均匀分布**，卡方拟合优度检验 χ²=5.00、p=0.287，无法拒绝均匀假设。也就是说——不存在一个能通吃所有任务的固定相位，这个自由度只能**逐 chunk 学出来**。

### 本文目标与切入角度

目标不是提升动作生成质量，而是回答一个被忽略的正交问题：**给定一个已经预测好的 action chunk，应该执行多久再停下来重规划？** 切入角度是「训练驱动 + 表征驱动」：保持基座 VLA 完全冻结，只学一个决定 *when* 的轻量策略。

### 三个技术难点（论文自己的归纳，也是方法三个组件的来源）

1. **候选步长有序且前缀共享**：50 步执行包含 40 步执行的全部前 40 个动作。标准 softmax 分类器把它们当作无序独立的类别，丢掉了这个结构。
2. **逐 chunk 监督不可辨识**：每次决策与后续 chunk 强耦合，同一个结果可以由不同的步长序列产生，不存在唯一的 ground-truth 停止标签。
3. **只用成功率作奖励会坍缩**：策略会退化到「尽量短的步长、疯狂重规划」，因为频繁重规划总体上更安全但浪费 VLA 调用。

## 方法详解

### 整体框架（Figure 2）

冻结 VLA 预测 chunk **a**ₜ = (aₜ¹,…,aₜᴴ) → BC Head 复用 chunk 预测过程中**已经算出来的**中间表征，输出 M−1 个 continue 概率 → 由概率链得到候选步长集合 ℰ = {e¹,…,e^M}（1 ≤ e¹ < … < e^M ≤ H）上的分布 → 采样 Eₜ，执行前缀 aₜ^{1:Eₜ} → 重新观测、再查 VLA。整个过程**不引入额外的 VLA 前向**。

### 关键设计 1：BC Head 的输入复用

头部吃三种 VLA 派生特征：视觉-语言 token **F**ₜ ∈ ℝ^{N×d_v}（场景与指令上下文），以及对每个动作步 j 的去噪动作 aₜʲ ∈ ℝ^{d_a} 与末步 action-velocity 特征 uₜʲ ∈ ℝ^{d_u}（暴露生成轨迹的运动级线索）。

$$\mathbf{h}_t^j = \mathrm{Proj}_a([\mathbf{u}_t^j; \mathbf{a}_t^j]),\qquad \hat{\mathbf{F}}_t = \mathrm{Proj}_v(\mathbf{F}_t)$$

拼上可学习 [CLS]，构成 **X**ₜ = [[CLS], **F̂**ₜ, hₜ¹,…,hₜᴴ]，送入一个 **2 层 Transformer encoder**，取 [CLS] 输出映射成 M−1 个 logits。

*为什么合适*：velocity 特征是 flow-matching / diffusion 类 VLA 免费的副产品，它比单纯的动作值更能反映「模型对这段轨迹有多确信」。**代价**是这套输入依赖基座是 flow/diffusion 结构（ACT 这类没有去噪过程的策略如何取 uₜʲ，论文未明确说明）。

### 关键设计 2：Bernoulli-Continuation 分解（核心贡献）

每个 logit 给出一个 continue 概率（式 3）：

$$p_t^i = \sigma(z_t^i),\quad i = 1,\dots,M-1$$

pₜⁱ 表示「从 eⁱ 继续执行到 e^{i+1}」的概率。于是选中 e^k 等价于前 k−1 次都选择继续、第 k 次停下（式 4）：

$$\pi_\theta(E_t = e^k \mid s_t) = \begin{cases}\left(\prod_{i=1}^{k-1} p_t^i\right)(1 - p_t^k), & 1 \le k < M\\[4pt] \prod_{i=1}^{M-1} p_t^i, & k = M\end{cases}$$

*为什么比 softmax 好*：这个因子分解和执行的嵌套结构同构——长步长只有在 chunk 被**反复**判定为可信时才可达，相邻步长自然获得相近概率。论文把它称为「有序、前缀共享的归纳偏置」。消融里这一项单独值 **+5 个点**（78% → 83%，Table 5）。

### 关键设计 3：Replanning-Efficiency Reward（RER）

相对效率项（式 7）以固定步长的参考轨迹 τ_ref 为锚，C 为 VLA 调用次数：

$$\eta_i = \tanh\!\left(\log \frac{C_{\mathrm{ref}}}{C_i}\right)$$

最终奖励（式 8），S_i ∈ {0,1} 为成功指示：

$$R_i = S_i\left(1 + \delta_+ \max(\eta_i, 0) + \delta_- \min(\eta_i, 0)\right),\quad \delta_+ = 0.7 > \delta_- = 0.3 > 0$$

三个要点：
- **成功仍然主导**：失败轨迹奖励恒为 0，策略无法靠「短而失败」的轨迹套利。
- **非对称**（δ₊ > δ₋）：省调用的奖励大于多调用的惩罚，因此「在关键阶段前多重规划一次」是被容忍的，只有在不改善成功率时才被压制。
- **顺带解决 GRPO 的组内退化**：二值成功奖励下，全成功或全失败的组优势为 0、梯度稀疏；效率项给全成功组打破平局，参考轨迹又让「fixed 成功但 adaptive 失败」的组产生负信号。只有参考与全部 adaptive 都失败的组才被丢弃。

### 训练：GRPO + 固定步长参考轨迹

每个任务实例采 G−1 条 adaptive 轨迹，**外加一条固定步长的参考轨迹 τ_ref 用于锚定优势**；轨迹级奖励广播到该轨迹的所有决策上；只有 adaptive 轨迹参与更新（τ_ref 无 BCP 决策）。裁剪目标（式 5–6）：

$$J_{\mathrm{BCP}}(\theta) = \mathbb{E}\left[\frac{1}{\sum_i T_i}\sum_{i=1}^{G-1}\sum_{t=1}^{T_i}\min\left(r_{i,t}\hat{A}_i,\ \mathrm{clip}(r_{i,t}, 1-\epsilon_{\text{low}}, 1+\epsilon_{\text{high}})\hat{A}_i\right)\right]$$

其中 Âᵢ = (Rᵢ − mean(ℛ)) / std(ℛ)，ℛ = {R₁,…,R_{G−1}, R_ref}。

## 亮点与洞察

- **问题定义本身是最大贡献。** Phase-shift 实验 + 最优相位的均匀性检验（χ²=5.00, p=0.287），两个实验就把「重规划时机」从一个被默认为超参的东西，变成了一个有 11.30% 头部空间、且证明**不可能用固定值解决**的独立研究问题。这种「先用廉价实验把自由度的价值量化出来」的写法值得借用。
- **序数分解可直接迁移。** 任何「选一个前缀长度 / 提前退出层数 / 采样步数」的离散决策，都天然有前缀共享结构，把 softmax 换成链式伯努利几乎零成本，本文给了 +5 点的经验证据。
- **奖励设计同时解决语义和优化两个问题。** RER 既表达了「省调用」的偏好，又顺手修好了二值奖励下 GRPO 组内优势坍缩；再加上「固定步长参考轨迹作为组内锚点」，这是一个很干净的把 baseline 塞进 group-relative 优势的做法。
- **正交性论证漂亮。** 现有 VLA RL（SimpleVLA-RL、πRL、π\*₀.₆、Q-chunking、AC3）都在改 *how* 生成动作、代价是更新大模型；本文只改 *when* 停，基座全冻，因此是即插即用的加法而非替代。
- **反直觉的经验结论**：自适应重规划**没有**变慢。因为无效执行步的减少超过了额外 VLA 调用的开销。

## 局限与展望

### 作者承认的局限

- BCP 只调整**何时停止执行并重规划**，不改动 VLA 生成的动作本身。当预测动作从根本上就是错的，换个时机重规划也救不回来。它治的是「时机错位」，不是「动作生成能力不足」。
- 展望：把自适应执行步长扩展到 World Action Model——这类模型同样生成多步 chunk，面临同样的问题。

### 需要注意的局限（我的判断）

- **消融与超参研究全部只在 *Hanging Mug* 单个任务上做**（Table 5 / A.3 / A.4）。RoboTwin Clean 评测环境 100 个，4–5 个百分点的差异在 n=100 下置信区间约 ±7–9 点，「BC Head vs Softmax = 83 vs 78」这类结论的统计强度是弱的。论文未报告任何方差、置信区间或多 seed 重复。
- **两个基线数字对不上**：Phase-shift 实验里 LingBot-VLA 的 50 任务成功率是 88.52%（Table 1），主表里 Clean 是 89.88%（Table 2）。论文未解释差异来源（大概率是评测 seed / 设定不同），但这也意味着 11.30% 的 gap 和 +4.06% 的增益不能直接相减来谈「还剩多少头部空间」。
- **Table 1 的上界是逐任务事后 oracle**，论文自己也标注了 attainable only in hindsight。它衡量的是「时机」这个自由度的价值上限，不是任何在线方法可达的目标。
- **候选步长下界限制了反应速度**：RoboTwin 最短 15 步（0.3 s @50Hz）、真机最短 30 步（0.6 s）。BCP 无法比这更快地对突发变化做出反应，本质上仍是粗粒度的分段常数策略，而非真正的闭环终止判据。
- **效率项只代理 VLA 调用次数**，不含真实 wall-clock、也不含「重规划落在正确阶段」的直接信号。好处是通用，代价是奖励对「时机对不对」只有通过成功率的间接监督。
- **奖励塑形依赖固定步长参考轨迹**，每组多跑一条 rollout（1/8 额外采样成本）；且「参考与所有 adaptive 轨迹全失败则丢弃该组」意味着**最难的任务在训练中被系统性地过滤掉**——这可能解释了为什么增益集中在「中等难度」的 13 个低成功任务上，而非最难的那批。
- **ACT 基座上的增益很小**（Rand 1.46→2.00），说明当基座本身能力不足时，调时机基本无用——与作者承认的局限一致，但也界定了适用范围：**BCP 是给已经「差不多能做对」的策略补最后一段的**。
- **缺一类基线**：没有与「学一个 value/critic 做终止判断」或「同时微调基座 + 学步长」的对比；Table 5 的 RL(Fixed-horizon) 是全量微调但固定步长，两个变量没有交叉。
- **可复现性**：代码与权重在项目页上是占位链接，截至阅读时不可用。真机部分（AGIBOT G1、自采 250+128 条轨迹）外部无法复现。

### 可做的下一步

1. 把序数伯努利链换成**逐步在线**的 continue 判据（每个控制步问一次，而不是 chunk 开始时一次性采样步长），代价是需要在执行中前向 head——但 head 只有 2.03 ms。
2. 奖励里加入显式的**阶段对齐**信号（如接触事件、夹爪状态变化前的重规划），把目前对时机的间接监督变直接。
3. 在被丢弃的「全失败组」上做课程或 relabel，避免最难任务无梯度。
4. 迁移到 world model / 视频预测类的 chunk 执行，正如作者展望。

## 评分

| 维度 | 分 | 理由 |
|---|---|---|
| 新颖性 | 4/5 | 自适应步长本身已有若干工作；真正新的是序数伯努利分解 + 效率感知奖励 + 冻结基座的组合，以及把问题量化出来的 phase-shift 实验 |
| 实验充分度 | 3.5/5 | 三个 benchmark、四种基座、真机验证、效率分析都齐；但消融集中在单任务、无方差报告、缺 critic 类基线 |
| 写作质量 | 4.5/5 | 动机—难点—组件的对应关系极清晰，三个难点直接映射到三个设计，附录该给的超参都给了 |
| 复现 / 落地价值 | 4/5 | 16M 参数、基座冻结、+2 ms 开销、真机 128 条轨迹即可训练，工程上极易接入；扣分在代码未放出 |
| 对当前研究的启发 | 4.5/5 | 「执行步长是一个被浪费的自由度」这个观察，对任何 chunk-based 部署都直接适用 |

## 实用要点

**可以借的**：① 序数伯努利分解替代 softmax（任何前缀共享的离散选择）；② 在 group-relative RL 里放一条确定性参考轨迹当锚点；③ 非对称的效率项（δ₊ > δ₋）来防止策略在安全方向上坍缩；④ 用 phase-shift / 相位均匀性检验的方式，先证明某个超参不存在固定最优值，再去学它。

**要小心的**：消融的统计强度、两个基线数字的不一致、以及「基座不够强时几乎无效」这个适用边界。

**它打开的问题**：如果「何时重规划」值 11 个点，那么 chunk-based 部署里还有多少个被当成超参钉死的自由度（预测步长 H、去噪步数、控制频率、观测刷新率）同样值这么多？
